# WISE-CITY-RP — الإصدار 2.0

سيرفر Roleplay عربي على **open.mp / SA-MP** بنظام وحدات متكامل (حسابات، فصائل، إدارة، سيارات ومزادات، منازل، بلدية، إسعاف، عصابات، حانة ومسرح، هاتف وسوق سوداء) مع Launcher فاخر.

## البنية

```
WISE-CITY-RP/
├─ gamemodes/
│  ├─ wise_city.pwn            الملف الرئيسي: التشغيل + توزيع كل الأحداث + الأوامر العامة
│  ├─ includes/
│  │  ├─ wc_core.inc           النواة: المكتبات + اتصال MySQL الواحد + طبقة التوافق
│  │  └─ wc_secrets.inc        بيانات قاعدة البيانات (عدّلها)
│  └─ modules/                 الأنظمة العشرة (wc_auth, wc_factions, wc_admin, ...)
├─ database/
│  ├─ 00_create_database_and_user.sql
│  └─ install.sql              كل الجداول (49 جدولاً) في ملف واحد
├─ launcher/                   واجهة الدخول (HTML/CSS/JS)
├─ server/                     config.json (open.mp) و server.cfg (SA-MP)
└─ tools/                      compile.sh / compile.bat
```

## المتطلبات
- open.mp (أو SA-MP 0.3.7) مع **pawncc**
- Plugins/Includes: `a_mysql` (R41-4)، `sscanf2`، `Pawn.CMD`، `streamer`، `samp_bcrypt`
- MySQL / MariaDB

## التثبيت
1. نفّذ `database/00_create_database_and_user.sql` بحساب root (بعد تغيير كلمة المرور).
2. نفّذ: `mysql -u root -p wise_city_db < database/install.sql`
3. عدّل `gamemodes/includes/wc_secrets.inc` بنفس كلمة المرور.
4. غيّر كلمة RCON في `server/config.json` (أو `server.cfg`).
5. صرّف: `tools/compile.sh` (أو `compile.bat`) ثم انسخ `wise_city.amx` إلى `gamemodes/` في السيرفر.
6. سجّل حسابك في اللعبة أولاً، ثم ضع رقمه (`users.id`) في `WC_OWNER_ACCOUNT_ID` داخل `wc_secrets.inc` وأعد التصريف؛ هذا الحساب وحده يملك صلاحيات المالك.
7. في الـ Launcher: عدّل `CONFIG.ip` و`CONFIG.port` في `launcher/script.js`.

## ما الذي تغيّر في هذا الإصدار
- **دمج الملفات العشرة في جيم مود واحد**: كانت 7 ملفات غير مضمّنة أصلاً.
- **إلغاء الـ Callbacks المكررة**: كل حدث يُعرَّف مرة واحدة في `wise_city.pwn` ويُوزَّع على الأنظمة بترتيب ثابت.
- **جدول حسابات واحد (`users`)** بدل `users` + `players`، واسم قاعدة بيانات واحد `wise_city_db`.
- **اتصال MySQL واحد** (`g_SQL`) بدل 7–10 اتصالات، وطبقة توافق R39→R41 للدوال القديمة.
- **الفصائل صارت على MySQL** (كانت ملفات نصية) مع مزامنة ترقيم الفصائل بين `users` ونظام الفصائل.
- **المال موحّد**: دينار اللاعب = رصيده داخل اللعبة ويُحفظ في `users.money_dinar` (المزادات والمنازل تتعامل معه مباشرة).
- **إصلاح تعارض أرقام الـ Dialogs** (1000 / 2001 / 3001 كانت مكررة).
- **إصلاح تعارض `IsPlayerAdmin`** مع الدالة الأصلية → أصبحت `HasAdminLevel`.
- **أمان**: كلمة المرور خرجت من الكود إلى `wc_secrets.inc`، والاستعلامات تستخدم `%e`.
- **ملف `Wise_City_BlackMarket.pwn`** كان في الحقيقة ملف SQL لنظام الهاتف؛ نُقل إلى `database/install.sql`.
- **Launcher**: تصميم جديد، مسارات صور صحيحة، وإزالة عدّاد اللاعبين الوهمي (يمكن ربطه بـ `statusUrl`).

## تنبيه مهم عن الاختبار
تم الدمج والتحقق بفحص ثابت (لا تعارض في الأسماء، ولا رموز تُستخدم قبل تعريفها، ولا Callbacks مكررة)، **لكن لم يُصرَّف الكود فعلياً** لعدم توفر pawncc أثناء العمل. توقّع في أول تصريف بعض التحذيرات (tag mismatch) وربما خطأ أو اثنين صغيرين حسب نسخة مكتبات open.mp عندك. أرسل لي مخرجات المترجم وأصلحها فوراً.

## ما بقي لإكمال المشروع
- الخريطة (Map) والمداخل والمركبات الحكومية (لا يوجد محتوى خريطة في المشروع).
- تغيير كلمات السر القديمة التي كانت مكشوفة في النسخة السابقة.
- اختبار شامل داخل اللعبة لكل نظام (خاصة المزادات والمنازل والفصائل).
- ربط حساب البائع غير المتصل في المزادات (الدفع للبائع يتم فقط إن كان متصلاً).
