# التصريف السحابي (بدون حاسوب)

1. ارفع هذا المشروع إلى مستودع GitHub جديد **Private**.
2. افتح تبويب **Actions** ثم **Compile gamemode** ثم **Run workflow**.
3. بعد دقائق: إن نجح تجد في Artifacts ملف `compile-result` فيه `wise_city.amx` و `compile.log`. وإن فشل افتح التشغيل وانسخ آخر 80 سطراً من خطوة **Compile** وأرسلها لي أو لـ Jules.

تنبيه: هذا الملف لم يُجرَّب. أخطاء المسارات أو أسماء المكتبات محتملة في أول مرة، ونصلحها من السجل كما فعلنا مع Unity.
