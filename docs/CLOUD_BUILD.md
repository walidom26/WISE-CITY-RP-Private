# 🛠️ دليل البناء السحابي التلقائي عبر GitHub Actions (GameCI Cloud Build)

توفر هذه الوثيقة الشرح الكامل باللغة العربية لخطوات تفعيل وتنقيل بناء لعبة **Wise City RP** تلقائياً عبر السحابة للاندرويد (APK) باستخدام منصة **GameCI** و **GitHub Actions**.

---

## 📋 الخطوات الأساسية لإعداد البناء السحابي

يتكون نظام البناء السحابي من أربع مراحل رئيسية:
1. **استخراج ملف التفعيل (.alf)** الخاص بـ Unity.
2. **تفعيل الرخصة الشخصية (Personal License)** والحصول على كود الرخصة.
3. **إضافة الأسرار (Repository Secrets)** في مستودع GitHub.
4. **تشغيل البناء السحابي وتنزيل ملف الـ APK النهائي**.

---

## 1️⃣ الخطوة الأولى: استخراج ملف التفعيل (.alf)

1. اذهب إلى المستودع الخاص بك على **GitHub**.
2. اضغط على تبويب **Actions** من القائمة العلوية.
3. اختر سير العمل **Acquire Unity Activation File** من القائمة اليسرى.
4. اضغط على زر **Run workflow** ثم اختر الفرع واضغط **Run workflow**.
5. بعد انتهاء التشغيل (سيعرض علامة صح خضراء ✅)، اضغط على اسم البناء واهبط لقسم **Artifacts**.
6. قم بتنزيل ملف `unity-activation-file` وفك الضغط عنه لتجد ملفاً ينتهي بـ `.alf`.

---

## 2️⃣ الخطوة الثانية: الحصول على نص الرخصة المحمية (UNITY_LICENSE)

1. افتح متصفحك واذهب إلى موقع تفعيل رخص Unity الرسمي:
   👉 [https://license.unity3d.com/manual](https://license.unity3d.com/manual)
2. قم بتسجيل الدخول بحساب Unity الخاص بك (`UNITY_EMAIL` و `UNITY_PASSWORD`).
3. قم برفع ملف الـ `.alf` الذي قمت بتنزيله في الخطوة الأولى.
4. اختر نوع الرخصة: **Unity Personal Edition** واختر الخيار الخاص بالاستخدام الشخصي/الطلابي.
5. قم بتنزيل ملف الرخصة المفعلة (الملف ينتهي بـ `.ulf`).
6. افتح ملف الـ `.ulf` باستخدام أي محرر نصوص (مثل Notepad أو VS Code) وقم بـ **نسخ النص بالكامل** بداخل الملف.

---

## 3️⃣ الخطوة الثالثة: ضبط أسرار المستودع في GitHub (Repository Secrets)

1. في مستودع المشروع على GitHub، اذهب إلى **Settings** ⚙️.
2. من القائمة اليسرى اختر **Secrets and variables** ثم اضغط على **Actions**.
3. اضغط على زر **New repository secret** وأضف الأسرار الثلاثة التالية:

| اسم السر (Secret Name) | القيمة (Value) |
| :--- | :--- |
| `UNITY_LICENSE` | النص الكامل الذي قمت بنسخه من ملف `.ulf` |
| `UNITY_EMAIL` | بريدك الإلكتروني المسجل به في حساب Unity |
| `UNITY_PASSWORD` | كلمة المرور الخاصة بحسابك في Unity |

> ⚠️ **ملاحظة أمان هامّة:** لا تقم أبداً بكتابة كلمات المرور أو كود الرخصة داخل الأكواد أو الملفات العامة. يتم حفظها فقط في أسرار GitHub المفرزة المشفرة.

---

## 4️⃣ الخطوة الرابعة: تشغيل البناء السحابي للاندرويد (Build Android APK)

يتم تشغيل نظام البناء السحابي يدوياً عند الحاجة لبناء النسخة:
* عبر تبويب **Actions** -> اختيار **Build Unity Android APK** -> الضغط على **Run workflow**.

---

## 5️⃣ الخطوة الخامسة: تنزيل ملف اللعبة النهائي (APK)

1. عند اكتمال عملية البناء السحابي بنجاح، اضغط على تشغيل البناء الأخير في تبويب **Actions**.
2. اهبط لأسفل الصفحة حتى تصل إلى قسم **Artifacts**.
3. ستجد ملف بحجم اللعبة الكامل واسمه **WiseCityRP-Android-APK**.
4. قم بتنزيله واستخراجه لتجد ملف الـ `APK` جاهزاً للتثبيت المباشر على أجهزة الأندرويد والهواتف الذكية!
